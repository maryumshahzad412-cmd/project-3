# project-3
Project 3: Hashing & Secure Storage  
This project introduces the concept of data integrity and secure password storage using hashing algorithms. The goal is to implement a program that converts user input (such as a password) into a fixed-length hash using functions like SHA-256, and then verify input by comparing hashes securely. Unlike encryption, hashing is a one-way process that cannot be reversed, making it ideal for protecting sensitive information. The project highlights the importance of using secure comparison methods to prevent timing attacks and discusses advanced practices such as salting and modern algorithms like Argon2id or bcrypt. By completing this milestone, interns demonstrate their ability to safeguard credentials and understand the foundation of secure authentication systems.
